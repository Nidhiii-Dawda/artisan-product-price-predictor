# Artisan Product Price Predictor

A machine learning-based application that predicts the selling price of artisan products using product, cost, sales, and seasonal features.

## Project Objective

The aim of this project is to help artisans estimate suitable product prices using machine learning based on historical product and business information.

## Machine Learning Models

Three regression models were developed and compared:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Evaluation Metrics

The models were evaluated using:

- MAE
- RMSE
- R² Score

## Final Model

The best-performing model was selected based on the evaluation results and used in the final application.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Streamlit

## Application

The final model is integrated into a Streamlit application where users can enter artisan product details and get a predicted product price.
